# Конструктор тренировок

Локальное приложение на HTML, CSS и JavaScript. Четыре утверждённых блока по шесть упражнений, разрешённые замены и независимые сохранения блоков. Источник исходных 58 упражнений и блоков — предоставленный `training-data.md`, версия 1.0. Схемы нагрузки и упражнения `ex059`, `ex060` добавлены по отдельным инструкциям пользователя v1.1/v1.2.

Опубликованный сайт: [chkmystyle.github.io/workout-builder](https://chkmystyle.github.io/workout-builder/). GitHub Pages публикует ветку `main`, папка `/ (root)`.

## Запуск

Откройте `index.html` двойным щелчком в современном Chrome, Edge, Firefox или Safari. Интернет, сервер, установка зависимостей и сборка не нужны. Все файлы приложения должны оставаться рядом.

## Файлы

- `index.html` — интерфейс и окно выбора упражнения.
- `style.css` — адаптивное оформление для компьютера и телефона.
- `exercises.js` — 60 упражнений, мышцы, типы движений, роли и признак односторонней нагрузки; описание, предупреждение и связь альтернатив для обратных отжиманий.
- `templates.js` — четыре блока, 24 уникальных ID позиций, исходные упражнения и точные списки допустимых вариантов. `allowedExerciseIds` включает исходный ID.
- `app.js` — выбор блока, проверка замен и уникальности ID, интерфейс, сохранение и сброс.
- `training-load.js` — схемы нагрузки по группе мышц, явным ID и роли упражнения; общие инструкции по отдыху и прогрессии.
- `tests/core.test.cjs` — необязательные проверки данных и правил; не нужны для запуска приложения.
- `tests/training-load.test.cjs` — проверки схем, приоритетов и совместимости сохранений.
- `tests/browser-check.cjs` — необязательные браузерные проверки отображения, замен, сохранений и мобильной вёрстки.

## Как пользоваться

Выберите блок и нажмите «Заменить» рядом с упражнением. На узком экране кнопка обозначена двумя стрелками. В окне показываются только разрешённые варианты, свободные в этом блоке, включая исходное упражнение. Выбор применяется сразу. Для сгибания ног в третьем блоке есть селектор «Сидя / Лёжа». У разгибания ног замены нет.

Сохранение выполняется автоматически в `localStorage` браузера, ключ `strength-workout-builder:v1`, версия схемы `1`. Каждый блок хранится отдельно внутри общего сохранения; выбранный блок также запоминается. «Сбросить тренировку» восстанавливает только открытый блок. Некорректный состав сохранённого блока восстанавливается целиком, а допустимые сохранения остальных блоков остаются. Повреждённый JSON или неизвестная версия схемы восстанавливают исходный цикл.

Сохранения относятся к текущему браузеру, профилю и расположению приложения. При переносе папки, открытии в другом браузере или очистке данных они могут быть недоступны. Поведение `localStorage` для `file://` зависит от браузера. Если браузер запрещает сохранение, приложение показывает сообщение и продолжает работать в памяти до обновления страницы.

Гравитрон указан как способ облегчить подтягивания с выбранным хватом и не имеет отдельного ID. Жимы из-за головы присутствуют в исходной библиотеке, но отсутствуют во всех меню замен. Ягодичный мост исключён.

## Схемы нагрузки v1.1

В каждой карточке указаны схема, количество подходов и повторения. «Подробнее о подходах» раскрывает порядок, типы подходов, назначение веса и пояснение к режиму. Общая рекомендация по отдыху видна под тренировкой; двойная прогрессия описана в разделе «Как выполнять и прогрессировать».

Приоритет выбора: группа «Мышцы корпуса» → 3×макс.; подтягивания `ex019`–`ex022` и отжимания `ex035`–`ex038`, `ex059`, включая брусья и обратные отжимания от скамьи → 5×12; роль «Основное» → 2+1+2; «Вспомогательное» → 2+2. При некорректной классификации вместо схемы показывается диагностическое сообщение.

Для брусьев предусмотрена отдельная подсказка: гравитрон с поддержкой для брусьев, если оборудование позволяет, либо обратные отжимания от скамьи без боли и с контролируемой амплитудой. Для обычных отжиманий сохранены прежние рекомендации. У `ex059` записано `alternativeForExerciseIds: ["ex038"]`: эта информационная связь предназначена для последующего использования и не расширяет разрешённые варианты существующих позиций. Брусьев в утверждённых блоках нет; обратные отжимания не подставляются в них автоматически.

Схемы выводятся из текущего упражнения и не записываются в localStorage. Ключ, версия и структура сохранений v1 сохранены: прежние замены работают без миграции. Вес не рассчитывается; учёт выполнения и таймер не добавлены.

## Изменения v1.2

- `unilateral: true` установлен для `ex007`–`ex011`, `ex025` и `ex045`: жима одной ногой, выпадов вперёд/назад, болгарских приседаний, зашагиваний, тяги гантели одной рукой и отведения руки с нижнего блока. В остальных записях отсутствие признака означает, что подпись не требуется. Неопределённые варианты попеременного выполнения не предполагаются автоматически.
- В сводке и каждом подходе таких упражнений показано «на каждую сторону»: 12 повторений в разминочных/подводящем и 12–15 в рабочих. Общий механизм также поддерживает односторонние вспомогательные упражнения и собственный вес, если этот признак будет установлен в их данных. Число подходов, диапазоны, отдых и прогрессия сохранены.
- `ex060` — «Подъём прямых ног к перекладине», группа «Мышцы корпуса», схема 3×макс. Разрешён только как дополнительная альтернатива в существующей позиции пресса `block1-position3`; исходные упражнения и порядок всех 24 позиций сохранены.
- `ex030` переименован в «Тяга каната к лицу (Face Pull)». ID и классификация сохранены, поэтому старый выбор этого упражнения остаётся действительным.
- `ex045` уточнён как «Отведение руки в сторону с нижнего блока». ID, классификация и схема 2+2 сохранены. `unilateralTarget: "arm"` уточняет подпись: два разминочных подхода по 12 и два рабочих по 12–15 повторений на каждую руку.

Новые параметры нагрузки не записываются в сохранения. Существующие данные v1.0/v1.1 загружаются без миграции и потери допустимых замен.

## Рабочая версия и откат

Исходная опубликованная версия сохранена в теге `stable-v1.0`, коммит `ba139bc50f5e38a76e04c3af97eb20070c009a63`. Предыдущая стабильная v1.1 сохранена в теге `stable-v1.1`, коммит `7c0c2bfa6dd26d89c98137671ea3b10475fdba67`. Для разработки v1.2 используется отдельная ветка `feature/training-updates-v1.2`; публикация выполняется после проверок объединением с `main`.

ZIP-снимки стабильных версий сохранены рядом с папкой проекта: `../workout-builder-stable-v1.0.zip` и `../workout-builder-stable-v1.1.zip`. Их можно распаковать в отдельные папки и открыть приложение независимо от текущей ветки Git.

После сохранения локальных изменений вернуться к v1.1 для проверки можно командой `git switch --detach stable-v1.1`; вернуться к доработкам — `git switch feature/training-updates-v1.2`. Для отката опубликованной v1.2 следует отменить коммит объединения командой `git revert -m 1 <merge-коммит-v1.2>`, проверить результат и отправить отмену в `main`. Найти коммит объединения можно через `git log --merges --oneline main`. Перезаписывать историю и использовать `push --force` не требуется. Сохранения v1.0/v1.1 совместимы с v1.2. При откате на v1.1 выбор нового `ex060` станет неизвестным старой библиотеке: прежняя проверка восстановит исходный состав затронутого блока; допустимые сохранения остальных блоков останутся.

## Необязательная проверка для разработчика

При наличии Node.js выполните из папки проекта:

```text
node --test tests/core.test.cjs tests/training-load.test.cjs
```

Для работы самого приложения Node.js не требуется.

Браузерная проверка предназначена для разработки и использует Playwright и установленный Chrome. При наличии этих инструментов выполните `node tests/browser-check.cjs`. Если Playwright доступен вне проекта, задайте переменную `WORKOUT_PLAYWRIGHT_PATH` с путём к модулю; при необходимости путь к Chrome задаётся через `WORKOUT_CHROME_PATH`. По умолчанию проверяется локальный `index.html` через `file://`; для локального предпросмотра можно задать `WORKOUT_TEST_URL`. Для запуска приложения эти инструменты не нужны.
