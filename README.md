# Конструктор тренировок

Локальное приложение на HTML, CSS и JavaScript. Четыре утверждённых блока по шесть упражнений, разрешённые замены и независимые сохранения блоков. Единственный источник библиотеки и блоков — предоставленный `training-data.md`, версия 1.0. Схемы нагрузки добавлены по отдельной инструкции пользователя v1.1.

## Запуск

Откройте `index.html` двойным щелчком в современном Chrome, Edge, Firefox или Safari. Интернет, сервер, установка зависимостей и сборка не нужны. Все файлы приложения должны оставаться рядом.

## Файлы

- `index.html` — интерфейс и окно выбора упражнения.
- `style.css` — адаптивное оформление для компьютера и телефона.
- `exercises.js` — 58 канонических упражнений, мышцы, типы движений и роли.
- `templates.js` — четыре блока, 24 уникальных ID позиций, исходные упражнения и точные списки допустимых вариантов. `allowedExerciseIds` включает исходный ID.
- `app.js` — выбор блока, проверка замен и уникальности ID, интерфейс, сохранение и сброс.
- `training-load.js` — схемы нагрузки по группе мышц, явным ID и роли упражнения; общие инструкции по отдыху и прогрессии.
- `tests/core.test.cjs` — необязательные проверки данных и правил; не нужны для запуска приложения.
- `tests/training-load.test.cjs` — проверки схем, приоритетов и совместимости сохранений.
- `tests/browser-check.cjs` — необязательные браузерные проверки отображения, замен, сохранений и мобильной вёрстки.

## Как пользоваться

Выберите блок и нажмите «Заменить» рядом с упражнением. На узком экране кнопка обозначена двумя стрелками. В окне показываются только разрешённые варианты, свободные в этом блоке, включая исходное упражнение. Выбор применяется сразу. Для сгибания ног в третьем блоке есть селектор «Сидя / Лёжа». У разгибания ног замены нет.

Сохранение выполняется автоматически в `localStorage` браузера, ключ `strength-workout-builder:v1`, версия схемы `1`. Каждый блок хранится отдельно внутри общего сохранения; выбранный блок также запоминается. «Сбросить тренировку» восстанавливает только открытый блок. Некорректный состав сохранённого блока восстанавливается целиком, а допустимые сохранения остальных блоков остаются. Повреждённый JSON или неизвестная версия схемы восстанавливают исходный цикл.

Сохранения относятся к текущему браузеру, профилю и расположению приложения. При переносе папки, открытии в другом браузере или очистке данных они могут быть недоступны. Поведение `localStorage` для `file://` зависит от браузера. Если браузер запрещает сохранение, приложение показывает сообщение и продолжает работать в памяти до обновления страницы.

Гравитрон указан как способ облегчить подтягивания с выбранным хватом и не имеет отдельного ID. Жимы из-за головы присутствуют в исходной библиотеке, но отсутствуют во всех меню замен. Ягодичный мост исключён.

## Схемы нагрузки v1.1

В каждой карточке указаны схема, количество подходов и повторения. «Подробнее о подходах» раскрывает порядок, типы подходов, назначение веса и пояснение к режиму. Общая рекомендация по отдыху видна под тренировкой; двойная прогрессия описана в разделе «Как выполнять и прогрессировать».

Приоритет выбора: группа «Мышцы корпуса» → 3×макс.; подтягивания `ex019`–`ex022` и отжимания `ex035`–`ex038`, включая брусья → 5×12; роль «Основное» → 2+1+2; «Вспомогательное» → 2+2. При некорректной классификации вместо схемы показывается диагностическое сообщение.

Схемы выводятся из текущего упражнения и не записываются в localStorage. Ключ, версия и структура сохранений v1 сохранены: прежние замены работают без миграции. Вес не рассчитывается; учёт выполнения и таймер не добавлены.

## Рабочая версия и откат

Исходная опубликованная версия сохранена в локальном теге `stable-v1.0`, коммит `ba139bc50f5e38a76e04c3af97eb20070c009a63`. Новая версия готовится в отдельной ветке `feature/training-load-v1.1`. Ветка `main` и GitHub Pages до подтверждения пользователя остаются на исходной версии.

Дополнительный ZIP-снимок исходной версии сохранён рядом с папкой проекта: `../workout-builder-stable-v1.0.zip`. Его можно распаковать в отдельную папку и открыть исходное приложение независимо от текущей ветки Git.

После сохранения локальных изменений вернуться к исходной версии для проверки можно командой `git switch --detach stable-v1.0`; вернуться к доработкам — `git switch feature/training-load-v1.1`. Для отката уже опубликованной v1.1 следует отменить её коммит командой `git revert`, проверить результат и отправить отмену в `main`. Перезаписывать историю и использовать `push --force` не требуется. Поскольку схема localStorage не менялась, сохранённые замены совместимы с обеими версиями.

## Необязательная проверка для разработчика

При наличии Node.js выполните из папки проекта:

```text
node --test tests/core.test.cjs tests/training-load.test.cjs
```

Для работы самого приложения Node.js не требуется.

Браузерная проверка предназначена для разработки и использует Playwright и установленный Chrome. При наличии этих инструментов выполните `node tests/browser-check.cjs`. Если Playwright доступен вне проекта, задайте переменную `WORKOUT_PLAYWRIGHT_PATH` с путём к модулю; при необходимости путь к Chrome задаётся через `WORKOUT_CHROME_PATH`. По умолчанию проверяется локальный `index.html` через `file://`; для локального предпросмотра можно задать `WORKOUT_TEST_URL`. Для запуска приложения эти инструменты не нужны.
